# WVST

WVST connects browser audio graphs to local VST3 plugins without loading third-party plugins inside the browser or Bridge Server. The web app owns the interface and routing. The local bridge owns discovery, worker supervision, and native processing.

Start with the [documentation](/docs), or open the [live rack demo](/demo) when the local bridge is running.
